# Gateway asset collection

Copied from `gateway-assets/` on 2026-10-23 under canonical project ID `gateway` (application repository: `web-gateway`).

- `astronaut/`: original and prepared character models.
- `planets/`: Games, Learning, Products and Tools scene sources, exports, design references and production scripts. These all belong to Gateway.
- `spacecraft/`: spacecraft production files.
- `inspection/` and `automation/`: inspection tools, milestone experiments, production evidence and integration contracts. Candidate code here is historical evidence, not application code to deploy.

Files retain their original paths relative to this collection and are not reclassified as approved by the import. Original files remain untouched.
