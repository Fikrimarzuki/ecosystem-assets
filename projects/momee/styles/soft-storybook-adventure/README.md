# Soft Storybook Adventure (active visual direction, M1.0m)

Momee's active visual direction since M1.0m (2026-10-26). It replaces **Calm Chibi Storybook**, which is now the *legacy / inactive* direction. Legacy artwork stays where it is, with its acceptance records unchanged (see [`../../visual-directions.json`](../../visual-directions.json)).

The design rules, the fidelity policy and the planned pipeline are in the app repository's style bible, [§13 of `app-momee/docs/design/visual-style-bible.md`](../../../../../app-momee/docs/design/visual-style-bible.md).
