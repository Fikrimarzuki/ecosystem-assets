# M1.1b: Mom head and upper-body SVG prototype (planned, not started)

**Status:** defined in M1.1a. **Nothing has been created.** Starts only on the owner's go-ahead. Specification: [`mom-visual-spec-v1.md`](mom-visual-spec-v1.md); reference: `../references/momee-soft-storybook-master-reference-v1.png`.

## Scope

A small first prototype: **Mom's head, hairstyle and upper body** (down to the waistband), neutral expression, in the reference's pose where practical.

- **Format:** editable, Inkscape-compatible SVG (named groups and layers, plain paths).
- **Construction:** carefully built Bézier paths with soft gradients and subtle shading, not generic geometric shapes.
- **Fidelity:** follow the reference; keep Mom's recognisable design (spec §5, priority 1).
- **Components:** separate where practical: `hair-back`, `head-skin`, `face-blush`, `face-eyes`, `face-brows`, `face-mouth`, `hair-front`, `outfit-top`, `body-skin`, arms and hands if included.
- **Pivots:** mark candidate pivots (head joint, neck base, eye centres, shoulders, elbow, wrist) as guides, without a rig.
- **Outputs (in `characters/mom/`):** the SVG source in `source/`, a transparent PNG export in `exports/`, and a side-by-side comparison with the reference in `review/`.
- **Stop** for owner visual approval.

## Not in scope

The lower body and shoes, a rig, animation, Phaser integration, other characters, and any application change.

## Acceptance checklist

| Area | Pass when |
| --- | --- |
| **Face likeness** | Same eye size and placement, brow arch, small nose and gentle smile; proportions match the reference at a side-by-side view; reads as the same Mom |
| **Hair silhouette** | The same side part, swept fringe, wide wavy volume and tapering ends; reddish-brown colour with a soft highlight band |
| **Colours** | Within a visible match of the sampled palette (hair `#84442d` and highlight `#c5704d`, skin `#fedebf`, coral blouse, soft brown outline); no black outline, no saturated drift |
| **Outfit** | Coral button blouse with pointed collar and gathered sleeves, correct proportion to the head |
| **Storybook finish** | Soft brown outlines, gentle gradients and controlled shading, rounded shapes; not flat, not photoreal, not generic corporate vector |
| **Editable structure** | Opens and edits in Inkscape; named, grouped components; no raster fills, no unresolved filters; paths are clean |
| **Blink potential** | The eyes are a separate group, and the eyelid area is organised so a closed-eye frame can be drawn |
| **Waving potential** | Shoulder, upper arm, forearm and hand can be separated (or are documented as to be drawn), with overlap areas identified |
| **Deviations** | Every meaningful deviation from the reference is listed for owner review |

## Entry conditions

The owner confirms the spec's §7 discrepancies (shoe colour, front view, pose) before construction starts.
