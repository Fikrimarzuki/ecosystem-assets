# Group 1 branding family

Shared notes for the seven Group 1 applications: **CV, Support, Playground, Projects, Tools, DevTools, Config Ecosystem**.

* Approved concept: [../../../references/branding/group1-refined-concept.png](../../../references/branding/group1-refined-concept.png). It is conceptual; clean masters are drawn from scratch, not cropped from it.
* Per-project work lives in `projects/<projectId>/branding/` once it exists (`cv`, `support`, `playground`, `projects`, `tools`, `devtools`, `configEcosystem`).
* Shared family files (palette tokens, tile geometry constants) go here when they are first needed.

Intended accents from the concept: CV mint/teal, Support cyan/blue, Playground purple, Projects mint/green, Tools gold, DevTools cyan/blue, Config Ecosystem green/teal.
